# Bright-Learn-Exercises
- This repository contains a collection of exercises and practicals completed as part of Bright Learn Data Science Course.

## Aim
- To demonstrate SQL fundamental skills.
-  To demonstrate SQL Advanced skills.
-  To demonstrate Databricks skills.
-  To demonstrate Google BigQuery skils.
-  To demonstrate knowledge of Business Analytics terminology.
  
## Objectives
- Complete exercise 1: SELECT and Filtering Statements
- Complete exercise 2: Aggregate functions and Grouping
- Complete exercise 3: CASE Statement
- Complete exercise 4: Joins, UNIONS, Filtering and Aggregate
- Complete exercise 5: NULL Functions
- Complete exercise 6: DATE Functions
- Practical 1-2 3: Databricks (SQL)
- Practical 3: Databricks Google BigQuery (SQL)
- PDF file of Business Analytics terminology

## Content
- Each exercise has 2 files: a pdf for Questions, and a pdf for Answers.
- Practicals consists of .sql code files and PDF code file
